# 🚢 SEA MERCHANTS

Smart India Hackathon prototype for data-driven maritime chartering decision support.

## Project Structure

- `frontend/` — web dashboard and user interface
- `backend/` — API, business logic and integrations
- `ai-ml/` — forecasting, risk analysis, voyage economics and vessel optimization
- `data/` — shared data documentation and dataset references
- `docs/` — research, architecture and SIH documentation
- `tests/` — project-wide testing

## Core Decision Pipeline

```text
User Input
    ↓
Freight Market Forecast
    ↓
Port Analysis
    ↓
Voyage Economics
    ↓
Risk Analysis
    ↓
Vessel Feasibility & Ranking
    ↓
Charter Timing
    ↓
Explainable Recommendation
    ↓
Human Decision
```

## Principle

SEA MERCHANTS is a decision-support system. The final chartering decision remains with the human decision maker.
