# Frontend

Frontend/dashboard workspace for SEA MERCHANTS.

## Responsibilities

- Cargo and voyage input forms
- Freight forecast visualizations
- Port risk presentation
- Vessel comparison table
- Voyage-cost breakdown
- Charter-timing comparison
- Explainable recommendation card

## Integration Contract

The frontend should consume the backend API rather than importing Python models directly.

Expected recommendation response should include:

- `freight_forecast`
- `port_risk`
- `vessel_recommendation`
- `vessel_ranking`
- `explanation`
